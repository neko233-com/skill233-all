## skill233-all 从零搭建并发布（完成）

需求：gh public 仓库 + 索引 neko233 自用 skill 与各业务领域好用 skill + 超快检索 + Cloudflare 发布 skill.neko233.com + 纯 vite-plus 前端无后端；后续补充：本质是超链接中心，业内 skill 走外链，Vercel 风格。

### 技术决策
- 构建：`vite-plus@1.6.0`（VoidZero 统一工具链，Rolldown 内核，CLI = `vp`）。`vp build` 正常，产物 dist/ ~312KB JS (gzip 74KB)。
- 前端：TypeScript + 原生 DOM，无框架（体积最小）。Vercel 风格 = 纯黑白 + Geist 字体 + 发丝边框 + 网格背景 + 三角 logo；卡片即外链（target=_blank），点开详情抽屉看安装命令。
- 超快检索：构建期生成倒排索引（`src/data/search-index.json`，flat [id,weight] 数组，3k+ tokens，108KB），运行时只 tokenize 查询。中文一元+二元分词、英文连字符分段、前缀匹配、多词 AND。共享分词器 `src/lib/tokenize.js`（构建+运行同一份）。

### 数据源
- `gh repo list neko233-com --visibility public` → 315 仓库，过滤后 313 mine。
- 业内精选 26 个（anthropics/skills、obra/superpowers、mattpocock/skills、ComposioHQ、VoltAgent、gamedev-skills 等），star 数由 `gh api repos/<full>` 拉取。中文简介与领域归类在 `scripts/build-catalog.mjs` 的 CURATED_OVERRIDES。
- 共 339 条，13 个业务领域。命令：`npm run data:fetch`（gh 采集）→ `npm run data:build`（生成 catalog/index/meta）→ `npm run build`。
